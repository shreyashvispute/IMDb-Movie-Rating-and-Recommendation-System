# IMDb Movie Rating and Recommendation System

## Overview
This project helps users explore movies using IMDb ratings, genres, and cast information.

## Features
- Display the top 10 highest-rated movies overall.
- Search by genre (for example, Action, Comedy, Drama, or Thriller) and display the top 10 matching movies.
- Search by actor or actress name and display their top 10 movies.
- Show available movie details such as title, IMDb rating, genre, cast, and release year.

## Setup
1. Install Python 3.
2. Clone or download this repository.
3. Install the dependencies listed in `requirements.txt`.
4. Add your project dataset to `dataset/`.
5. Add your application code and run command below once configured.

```bash
pip install -r requirements.txt
```

## How to Use
- Choose the overall top-rated movies view to see the top 10 movies.
- Enter a genre to see the top 10 movies in that genre.
- Enter an actor or actress name to see their top 10 movies.
